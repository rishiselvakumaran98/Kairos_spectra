# KAIROS-SPECTRA Icons

This directory should contain extension icons in the following sizes:
- icon16.png (16x16)
- icon48.png (48x48)
- icon128.png (128x128)

For development, you can use placeholder images or generate icons using the following tools:
- https://www.favicon-generator.org/
- https://realfavicongenerator.net/
- Figma/Sketch/Adobe XD

## Recommended Design

The icon should visually represent:
- **Analytics/Data**: Charts, graphs, or visualization elements
- **Proactivity**: A spark, lightbulb, or assistant metaphor
- **Trust**: Clean, professional design

## Color Palette Suggestion

- Primary: #3b82f6 (Blue - representing trust and intelligence)
- Accent: #10b981 (Green - representing growth and insights)
- Background: White or transparent

## Quick Placeholder Generation

Until custom icons are created, you can use a simple colored square:

```bash
# macOS/Linux with ImageMagick
convert -size 16x16 xc:#3b82f6 icon16.png
convert -size 48x48 xc:#3b82f6 icon48.png
convert -size 128x128 xc:#3b82f6 icon128.png
```

Or use an online tool like https://placeholderlogo.com/
